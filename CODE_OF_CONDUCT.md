# Code of Conduct

This applies to issues, pull requests, reviews and every other project space.

- Critique code and decisions, not people.
- No harassment, personal attacks, or insulting or discriminatory language.
- Assume the other person read the issue; ask before concluding they did not.

The maintainer may edit or remove comments, lock threads, and block accounts that break this.

Report a problem to **luminary.oss@gmail.com**. Reports are read only by the maintainer and kept
private.
