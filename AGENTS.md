# Agent instructions

This repository's agent instructions are in [CLAUDE.md](CLAUDE.md). Read it first and follow it;
it is the single copy, so this file only points to it.

When preparing a pull request for a contributor:

- The issue it closes must carry the `accepted` label (`CONTRIBUTING.md`).
- Run `make ci` and report its result as output, not as a claim.
- Commits are signed off by the contributor (`git commit -s`), whose identity it certifies.
- Leave the template's AI-use section and its "read every line" box for the contributor.
